# Rule-Based Chatbot (Project 1)

## Overview
This is a simple, rule-based conversational chatbot built in Python. The chatbot accepts user input, processes it, and responds based on a pre-defined set of natural language mappings. 

## Features
- Interactive command-line interface.
- Basic text matching using dictionary lookups.
- Normalizes input by converting to lowercase and stripping excess whitespace.
- Recognizes basic greetings, help commands, and basic inquiries about AI.
- Clean exit sequence.

## Prerequisites
- Python 3.x

## How to Run
Run the script directly from your terminal:
```bash
python part1.py
```

## Example Interaction
```text
Chatbot is online. Type 'exit' to quit.

You: hello
Bot: Hi there! How can I help you?
You: what is ai
Bot: AI is the simulation of human intelligence by machines.
You: exit
Bot: Shutting down. Goodbye!
```
